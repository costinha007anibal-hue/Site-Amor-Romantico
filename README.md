# Para a Filipa 🌷

Site romântico e interativo dedicado à Filipa, com tema de tulipas.

## Estrutura do site

1. **Hero** — Nome + coração interativo
2. **Carta de amor** — Mensagem personalizada
3. **Porque gosto tanto de ti** — 6 cartões interativos (flip)
4. **Jardim de tulipas** — 8 tulipas clicáveis com mensagens secretas
5. **O que quero para nós** — Timeline de promessas
6. **Surpresa final** — Chuva de tulipas e corações

## Personalização

Edita o `index.html`:
- Textos da carta
- Mensagens dos cartões (`data-message`)
- Mensagens das tulipas (`data-msg`)
- Timeline

## Como abrir

Abre o `index.html` no browser ou publica em Netlify / GitHub Pages.

Feito com carinho.
